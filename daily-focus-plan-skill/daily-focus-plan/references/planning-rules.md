# Planning rules

SYNTHETIC teaching example. These are assumed personal preferences, not an organization’s policy.

- Reserve 10 minutes of the available time as a buffer. If fewer than 10 minutes are available, ask the user how much buffer to reserve.
- Put tasks due today ahead of later deadlines. An unknown deadline is not evidence that a task is unimportant.
- For equal deadlines, ask about priority when the choice matters.
- Never shorten a task estimate just to make the plan fit. Defer it or ask the user to reduce its scope.

In the output, distinguish the buffer from time allocated to tasks.
